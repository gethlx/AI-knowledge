## 三维浏览

冻结197卡/1562边只读副本用于完整预览，不成为新事实源或回写真源。全197节点/1562边一次载入；focus为历史元数据，不再剪裁场景。点击任何概念均不重建范围、播种坐标或求解对象。

位置使用D3三维原生初始布局及现有拓扑距离/charge参数求解，目标长度变化只是排布启发式，不代表知识关系强弱。没有固定selected节点。真实节点/名称拖动沿用库原生D3交互；松手释放临时固定，最多75步或1.2秒稳定。单纯点击不会继续重排，选中颜色直接更新材质。

首次进入定位阅读概念一次；全景拟合全部197节点，定位按钮主动回当前概念。点击名称只更新详情并单次定位420ms；手势可打断，随后相机不追随selected。普通空白左键/单指旋转，右键空白平移，双指空白缩放/平移，是原生Orbit映射；滚轮zoomToCursor。直接拖小锚点或名称为节点排布变化，不是平移相机。

大图标签按视口投影和距离避让，不按selected/邻接身份分级，不设固定数量上限；移动/旋转期间仍显示眼前区域的名称。只有当前正在拖动的名字得到临时优先。getState.preferredLabels是旧接口保留的单次镜头框定样本，不参与标签显示规则；labelPolicy=viewport，scope=full。

名称SpriteText与节点位于同一三维场景，14px固定屏幕字号（缩略9px）；禁用标签雾色，renderOrder=30，高于原生连线10；隐藏标签不命中。普通边材质透明度80%，当前概念边92%；只依空间距离加Fog深度提示（观察距离×0.65到×1.35），不按是否邻居隐藏边。正文缩略入口仍只展示当前名称，展开后可自由发现其他知识节点。

原生指针结束兼容处理及未移动点击停止力学重启，见50号；没有修改依赖源码。

## 文件和接口

- atlas.html / src/styles/atlas.css：页面骨架、视觉、原地details及大图/缩略容器。
- src/ui/atlas-preview.js：可替换的预览控制器。唯一HTML渲染控制器，不是WB正式src/data、src/graph或src/state。
- src/ui/preview-data.json：197卡/1562边只读副本；public/assets：独立字体、纸山背景及许可。
- src/ui/vite.config.js：独立atlas构建，dist-ui；原index.html/smoke.js与默认安装测试入口保留。

| API | 最新语义 |
|---|---|
| selectConcept(id) | 主详情更新并单次定位；不强制滚动到页顶；完整场景/节点坐标保持，标签随视野显示 |
| setMode('reading'/'explore') | 仅图谱缩略/展开，主正文不换页、不折叠，不把阅读滚动位置重置 |
| focusSelected() | 定位当前节点；旧“点击不移动镜头”约定已被用户新要求替代 |
| getState() | selected/focus/mode/overview/scope/labelPolicy/preferredLabels/labelBoxes/visible/edgeCount/camera等；preferredLabels不再控制显示 |
| readCard/getNeighbors/graph | 卡文、全部邻居分组、当前场景；开发交接用途 |

atlas:selection和atlas:mode事件保留。#graph-surface整体移到缩略或展开容器，#node-labels只供键盘访问，不承担视觉叠层。来源和认知字段保留在输入层，不必在阅读UI补回。
