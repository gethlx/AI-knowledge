# Codex HTML与WorkBuddy接口交接（48号）

本地入口：http://127.0.0.1:41839/atlas.html。`?view=explore`仅表示打开大图，不再表示另一套正文页面；`#card_id`为内部深链，编号不向读者展示。48号为当前行为，47号保留上一轮连续阅读/定位修订，45/46号保留历史。

## 当前页面与内容

沿用纸面底色、宋体、本地图标、正文优先及首屏缩略入口；480px最大阅读宽度，320/390/430px验证，宽屏不新做桌面版。

正文只有定义和解释说明：精确定义原文；解释合并教学类比、典型案例、常见误解、反例、安全与伦理边界，保留字段文本，用行内提示区分误解/反例。来源依据/深度上限不展示，主详情不展示认知徽标；认知分类仍供目录筛选。原始字段没有删除或改写，缺项不补造。

48号移除“上一个概念”UI及相邻概念筛选框；保留全局搜索/目录及浏览器原生历史。相邻导航使用浅绿底、28px留白及2px顶部线与纸色正文区分。解释说明用原生details在当前位置展开/收起。相邻概念为完整分组清单，每项原地展开定义/已有解释，向下拉长文档，不更新selected、URL、相机或主标题；缺少解释时没有空标题。主正文与相邻概念都不切换页面状态。

## 三维浏览

冻结197卡/1562边的只读副本用于局部预览，不能成为新事实源或回写真源。初始focus=selected，取全部一跳邻居及其诱导边：大语言模型42/266，生成式人工智能62/404。

节点位置通过现有d3-force-3d求解；连线目标距离按节点度与共同邻居比例变化（只是布局启发式，不是语义权重），不再统一distance(32)或人为压缩后固定fx/fy/fz。预热结束停止漂移。

默认镜头以当前节点及附近直接邻居为阅读尺度；全景按钮单独拟合当前局部网，定位按钮回当前概念，+/-、滚轮及双指均缩放空间。点击可见节点/文字只定位一次，平滑420ms；减少动态偏好时立即定位。开始手势时取消定位动画，后续相机不与selected绑定。普通鼠标拖动/手机单指为PAN，右键拖动为ROTATE，双指为DOLLY_ROTATE，滚轮zoomToCursor=true；视点随平移/指针缩放自由移动。主动定位按钮才再次回中。选中时仍保持可见节点的位置/边集合，选中图内节点不会重建布局；搜索/目录选中图外节点才建立它的完整局部网。

SpriteText留在同一三维场景，关闭sizeAttenuation，按视口高度校准14px文字（缩略9px），不能随镜头距离整体放大。优先当前节点和6个最近的直接邻居，按真实屏幕矩形避让；旋转中保留优先邻居而精简背景名称。标签与线共享空间锚点、镜头，文字优先点击，拖动>6px不误选。

## 文件和接口

- atlas.html / src/styles/atlas.css：页面骨架、视觉、原地details及大图/缩略容器。
- src/ui/atlas-preview.js：可替换的预览控制器。唯一HTML渲染控制器，不是WB正式src/data、src/graph或src/state。
- src/ui/preview-data.json：197卡/1562边只读副本；public/assets：独立字体、纸山背景及许可。
- src/ui/vite.config.js：独立atlas构建，dist-ui；原index.html/smoke.js与默认安装测试入口保留。

| API | 最新语义 |
|---|---|
| selectConcept(id) | 主详情更新，单次定位并优先显示直接邻居；不强制滚动到页顶；图外概念才重建局部网 |
| setMode('reading'/'explore') | 仅图谱缩略/展开，主正文不换页、不折叠，不把阅读滚动位置重置 |
| focusSelected() | 定位当前节点；旧“点击不移动镜头”约定已被用户新要求替代 |
| getState() | selected/focus/mode/overview/preferredLabels/labelBoxes/visible/edgeCount/camera等预览核验信息 |
| readCard/getNeighbors/graph | 卡文、全部邻居分组、当前场景；开发交接用途 |

atlas:selection和atlas:mode事件保留。#graph-surface整体移到缩略或展开容器，#node-labels只供键盘访问，不承担视觉叠层。来源和认知字段保留在输入层，不必在阅读UI补回。
