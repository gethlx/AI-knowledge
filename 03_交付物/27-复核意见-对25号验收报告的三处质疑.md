## 质疑一（要害）：待核定清单口径不完整，实际缺口 412 对而非 229 对

25 号报告 §1 与 §5 称："260 份历史裁定缺少结构化 `adopted_relation`，其中 229 份标为 ACCEPTED"。**这个口径只覆盖了 `batch_mode=None` 的子集。**

以报告自己保全的凭据文件 `04_归档/图谱关系审计凭据/adjudications.jsonl`（1,907 份，"不补字段、不改文字"）为准，全量核验：

```bash
python3 - <<'EOF'
import json
from collections import Counter
recs = {json.loads(l)['pair_id']: json.loads(l)
        for l in open('04_归档/图谱关系审计凭据/adjudications.jsonl')}
acc = set()
with open('02_分析产物/p5_review/accepted_model_adjudicated_edges.jsonl') as f:
    for line in f:
        acc.add(json.loads(line)['pair_id'])
accepted = {p for p, r in recs.items()
            if 'ACCEPT' in str(r['final_status']).upper()}
miss = accepted - acc                      # ACCEPTED 但未入图
print('ACCEPTED 未入图总数:', len(miss))    # → 439
print('其中 adopted_relation=null:', sum(1 for p in miss if recs[p].get('adopted_relation') is None))  # → 412
print('412 对的 batch_mode 分布:', Counter(recs[p].get('batch_mode') for p in miss if recs[p].get('adopted_relation') is None))
print('有 adopted_relation 却未入图:', [(p, recs[p]['adopted_relation']) for p in miss if recs[p].get('adopted_relation')][:3])
EOF
```

**实测结果**：

| 口径 | 数量 | 说明 |
|---|---|---|
| ACCEPTED 未入图（全量） | **439** | 1,815 ACCEPTED − 1,376 入图 |
| 其中 `adopted_relation=null` | **412** | 真正语义不明、需核定的部分 |
| —— batch_mode=None | 229 | 25 号报告已覆盖 ✓ |
| —— mega | **132** | 25 号报告**未覆盖** |
| —— unanimous-programmatic | **26** | 同上 |
| —— manual-web | **15** | 同上 |
| —— manual-web-escalated | **10** | 同上 |
| 其中 adopted_relation = no_relation / insufficient_evidence | 27 | 全部 tier2-matrix，裁定结论即"无关系"，**合理不入图**，双方无争议 |
| 已入图 1,376 对 | 凭据 `adopted_relation` 100% 非空 | ✓ 与报告"已入图边均可对应结构化裁定"一致 |

**质疑点**：25 号报告把"缺结构化关系"的判定口径锚定在 `batch_mode=None`（260 份）上，而按它自己"不补字段、不改文字"的凭据文件，`adopted_relation=null` 的 ACCEPTED 共 **412 份**——**多出 183 份（mega 132 / unanimous 26 / manual-web 15 / manual-web-escalated 10）未被纳入《裁定缺字段待核定清单》**。若这些对中存在与 `1-01__1-02` 同类的情况（文字理由描述了真实关系但字段为空），则当前图不止缺 229 份裁定对应的关系。

**要求**：待核定清单从 260 对扩至 **412 对**（或逐条给出这 183 对"字段为空但无需核定"的证据——例如原始模型输出中确认为无关系的独立凭据；若拿得出，臣认错）。
