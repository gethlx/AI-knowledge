## 当前交互约定

同一页面、同一选中概念、同一个详情面板，只有探索和阅读两种展示状态。阅读为默认状态，正文优先，图谱收成首屏缩略；展开关系网时放大同一场景，详情面板收为下方预览。详情面板向上展开或点击“展开阅读”，进入阅读状态，不加载第二套词条页面。顶部导航保持一致。

| 操作 | 必须发生的结果 |
|---|---|
| 点击球形节点或其文字标签 | 高亮该节点，底部直接显示其名称、定义及展开阅读操作；不自动重建它的邻居子图、不自动居中或飞行 |
| 展开阅读 / 上拉面板 | 同一概念正文扩大，关系网收为缩略；阅读按内容滚动 |
| 收起正文 / 展开关系网 | 恢复原图谱视角和缩放，同一选中概念及正文阅读位置保留 |
| 点击相邻概念中的词条 | 与图中点击一致，直接更新该词条详情；保留当前展示状态，不先显示邻居页 |
| 查看它的关系 | 用户主动请求后才围绕选中概念聚焦其关系；此操作与点节点分开 |
| 返回上一概念 | 恢复上次概念、正文滚动和展开状态；若曾主动聚焦图谱，同时恢复上次视角与图谱焦点。首次直接进入无历史时不虚构上一个概念 |
| 点击同一已选概念 | 不重新置顶正文，不重复加入浏览历史 |

必须区分“正在阅读的概念”和“图谱当前聚焦的概念”。在A关系范围内点击B，只更新正文和选中高亮，图谱仍是A的范围；点击“查看它的关系”后才聚焦B。图中的“当前关系”不能在选择变化时悄悄改含义，操作提示或当前关系控件可按需说明其聚焦对象。图范围外的词条通过搜索/目录打开时也先显示正文，图谱聚焦由明确操作完成，不伪装高亮不存在的可见节点。

相邻概念收为详情面板内的次要折叠区，无独立路由。全部条目来自当前详情概念的真实关系，计数随概念变化；大语言模型为41项，2入向前置/1出向前置/38关联。保留“先了解这些概念”“以它为基础”“其他关联”直白分组，方向不改。面板展开、折叠和关系网手势不能互相争抢滚动：详情区滚动正文/清单，图谱区旋转缩放。拖动手柄并非唯一入口，按钮也可切换。
