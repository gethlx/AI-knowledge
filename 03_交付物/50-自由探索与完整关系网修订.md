## 结论与上一轮验收缺口

限制自由探索的主要原因是我们添加的业务筛选，而不是三维库缺少拖动/缩放功能。49号只证明节点会变形、相机与基本控件能操作，没有覆盖“保持主正文 → 移向非邻居区域 → 局部放大 → 发现更多知识节点”的使用路径。此次按这条路径核验。

## 哪些是原生交互，哪些是我们改过的规则

原生依据：[3d-force-graph接口](https://github.com/vasturiano/3d-force-graph#api-reference)、[官方Orbit运行示例](https://vasturiano.github.io/3d-force-graph/example/controls-orbit/)、[官方示例源码](https://github.com/vasturiano/3d-force-graph/blob/master/example/controls-orbit/index.html)。库默认控制器为Trackball；本项目采用它已有的Orbit方案，不自写旋转/平移/节点力学控制器。本地另建同197/1562数据的无业务筛选原生Orbit基线，实际操作鼠标旋转、右键平移和滚轮；鼠标/触摸映射与项目一致。该基线仅供比较，不是新增产品入口。

| 规则 | 49号及更早的自定义 | 50号处置 |
|---|---|---|
| 场景范围 | 只取当前focus的一跳邻居及诱导边；图外概念须切换后才出现 | 全部197节点/1562边一次载入；读哪个概念不裁剪场景 |
| 初始排布 | 自行球面播种，focus位于原点 | 移除中心播种；采用D3三维原生初始坐标求解，无选中节点固定位置 |
| 标签优先级 | selected → 六个直接邻居 → 其他邻居 → 背景；手机硬上限约13 | 视口内按投影位置和空间远近避让；不以selected或邻接身份分级，无大图固定数量上限 |
| 移动中的信息 | 移动/自动旋转时隐藏非优先邻居名称 | 平移、旋转、缩放中仍显示所在区域的名称；正在拖动的那个名称保留 |
| 连线强弱 | 当前概念连线62%，其他仅18% | 当前连线92%，其他80%；没有按邻接身份隐藏的边。深度淡化只依空间距离 |
| 手势 | 曾在48号关闭节点拖动并把普通拖动改为PAN | 节点/名称拖动仍为库原生D3交互；空白左键/单指旋转、右键平移、双指空白缩放/平移，采用Orbit原生映射 |
| 点击与视点 | 自定义单次居中420ms、移动打断、滚轮围绕指针缩放 | 保留已确认行为；操作后不追随selected。第一次进入仍定位阅读概念一次，全景显示整个网 |
| 布局距离 | charge -125、link strength .14；目标长度根据节点度/共同邻居而变化 | 保留以避免统一目标边长；只是布局启发，不是知识关系强弱或新事实 |
| 正文/导航 | 49号默认前置/以它为基础展开、其他关联收起，详情原地展开 | 保留，探索相机移动不更新正文；点击新概念才更新主详情 |

尚保留的视觉适配：小锚点、固定14px名称（缩略9px）、长名称换行、纸色标签背景、屏幕碰撞避让；这些仍是我们自己的显示适配，不宣称属于原生默认。三维库默认只有悬停名称提示，不能直接替代手机可读标签。

## 连线与选择的实现处理

提高其他连线对比后，全197节点视图的远处1562边会遮挡。采用[Three.js原生Fog](https://threejs.org/docs/pages/Fog.html)作为距离深度提示：near=当前观察距离×0.65、far=×1.35，随视点变化；不基于关系种类或选中概念筛掉远处事实。近处普通边仍使用80%材质透明度，远处随距离淡化。名称不参加雾色淡化，且绘制顺序高于原生连线，保证文字与纸色底板清楚。

选择仅更换场景材质，不调用会重新初始化力学对象的颜色属性设置。库原生DragControls在单纯点击后也会重启求解；本预览对未移动的节点点击停止这次重启，真实拖动仍启动力学，防止点击时整个网继续重排。沿用49号真实pointerup/pointercancel清理控制器指针状态的兼容处理，依赖源码没有修改。这些是明确保留的适配，不隐称完整照搬原生默认。
