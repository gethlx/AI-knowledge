# B 路线：直接 HTML 先行

## 独立设计输入
仅阅读冻结卡片 `card_evidence.jsonl`、G_v2 `graph.json` 及 HTML / HTML Prototype / Design Artifact / Playwright 技能。未阅读旧页面、旧截图、旧设计讨论或 A 路线产物。没有使用外部模型或生图。

## 编码前设计判断
- 用户与任务：手机读概念，按需要补充案例、误解、安全边界；遇到相邻概念可以跳转后继续原来的阅读。
- 形式与范围：可直接打开的单文件交互知识图册；初始词条 4-03 大语言模型。
- 视觉语气：像可随身阅读的科学词条，标题、定义与释例有区别；目录通过按钮打开，不占首屏。
- 色彩计划：纸面 #ffffff；底色 #f1f5f7；墨色 #183344；辅助墨色 #536a76；阅读强调 #12645b；浅强调 #e7f4ee。深色以蓝灰纸面与浅绿强调对应。
- 字体：标题/定义用系统宋体（Songti SC / STSong），正文用系统黑体（PingFang SC / Microsoft YaHei），编号及英文用系统衬线与等宽辅助。无字体网络依赖。
- 组织方式：居中的单一阅读页；关系放在词条下方，手机底部有直达按钮。桌面仍以阅读为中心，不把画布或目录做成主角。
- 状态：当前词条、展开字段、页面位置、导航来源、查询、空结果、主题；历史返回恢复展开和位置，目录对话框支持 Escape 和焦点恢复。
- 内容守恒：所有卡片原文字段保留；不创造测验、掌握程度或未确定的教学顺序。先修只用 effective_source → effective_target，related 对称。

## 检查记录
- 浏览器独立会话：`htmlb20261002`，通过指定的本地只读服务测试；未访问目录列表、A 路线或 kgcompare 会话。
- 渲染：已实际查看 390×844 手机浅/深色截图和 1440×1000 桌面截图；320×760 窄屏也无页面横向溢出。
- 首屏：目录关闭，直接展示定义和教学类比。深色正文及强调区域读取了实际计算颜色。
- 内容：嵌入的 197 张卡片与冻结 JSONL 完整对象相等；1562 条关系的类型及有效端点与 graph.json 相等。4-03 的 9 个原文字段均在词条 DOM 中可访问。
- 关系：4-03 为 2 先修、1 后续、38 对称相关；展开其余相关概念后共 41 个真实邻居入口。首组相关概念选了 Token、提示、幻觉、上下文窗口，其他相关概念在同一个披露控件中，未暗示掌握程度或关系强度。
- 返回：打开案例和安全边界→跳到相邻关系→幻觉→页面“返回”按钮，返回前后 y 均为 1164.5px，展开状态均为 examples / safety，焦点恢复到 neighbor-4-12。浏览器后退也实际通过同一恢复检查。
- 目录：编号搜索 4-12 可跳转；无结果有提示；Escape 关闭并恢复找概念按钮焦点；Shift+Tab 检查焦点仍在原生对话框内。
- 键盘：披露控件 Enter 展开、Space 收起实际通过；使用可见焦点样式，邻居跳转后聚焦概念标题。
- 主题：操作系统深色和显式浅/深切换通过；减弱动态偏好已启用检查，页面没有必要动画。
- 自包含：外部脚本和样式依赖为 0；本地服务加载后没有脚本执行错误。最初浏览器请求缺省 favicon 404，加入内联 favicon 后已修正。

## 验证边界
- 浏览器工具阻止 file: 协议访问，故“从磁盘双击直接打开”的运行未能在此工具中实测；已核对内联数据、样式、脚本，无 fetch 或网络依赖，并通过本地 HTTP 实测。
- 这是聚焦一个阅读导航闭环的独立原型，没有全图画布、编辑、账号、测验或学习状态。已验证原文保持与导航行为；不代表课程内容的新增语义评审或真实学生使用验收。
- Playwright CLI 自动生成了自己的快照日志；指定交付目录中的人工交付物仅 route-b.html、route-b-notes.md 和 route-b- 开头截图。
