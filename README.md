# 银河 AI 知识图册

**一个帮助学生查概念、读解释、看懂知识联系的轻量教学工具。**

> 访问状态：当前没有可直接点击使用的在线演示地址。运行图册需要先下载项目并启动本地服务，步骤见下方「如何访问」。

本项目从「银河AI通识课程体系」整理出197个AI概念，将概念解释与知识关系放在同一个移动优先的网页中。读者可以搜索一个词，阅读定义和通俗说明，再通过三维关系网或相邻概念继续探索。

它适合学生在课堂内外查阅，也可供教师讲解概念之间的联系。知识内容覆盖四至八年级AI通识课程涉及的主要主题；概念卡不是一节课，关系网也不规定唯一学习顺序。

日常浏览直接读取本地数据，不调用大模型API；页面可以构建为静态文件，不需要为阅读功能运行知识库服务。

## 可以怎样使用

例如，从「大语言模型」开始：

1. 搜索中文或英文名称，打开概念。
2. 阅读精确定义，按需展开通俗解释、案例和使用边界。
3. 展开三维关系网，旋转、缩放或拖动节点，查看附近的概念；点击节点或名称即可阅读其详情。
4. 在正文下方查看「先了解这些概念」「以它为基础」「其他关联」，直接展开相邻词条阅读。
5. 使用浏览器前进、后退继续浏览，恢复阅读与图谱状态。

页面以正文为主，三维网提供探索入口。图中的小锚点、文字和连线处于同一三维场景；距离、位置和线长用于排布，不代表概念的重要性或关系强弱。

目前有197个概念、1562条关系，包括1484条关联和78条有方向的前置关系。前置关系表示理解后一个概念前，需要先了解前一个；关联表示概念之间存在联系，不自动意味着学习顺序。前置关系已通过无环检查。

关系经过多模型评审与裁定，尚未经人工逐条核验，应作为教学辅助。每张卡的认知层级和内容深度有各自边界，原资料未提供的字段不自动补造。

## 如何访问

**当前仓库提供源代码和本地运行方式，尚未提供已验证可用的在线演示入口。** 在GitHub中点击README或HTML源文件不会运行知识图册。下面的本机地址只在完成启动步骤后有效，不是部署好的网站地址。

### 在自己的电脑运行

先安装 **Node.js 22.12或更高版本（含npm）**，并使用支持WebGL的浏览器。通过Git下载项目时，在终端执行：

```bash
git clone https://github.com/gethlx/AI-knowledge.git
cd AI-knowledge/02_分析产物/图谱浏览器开发环境
npm ci
npm run dev
```

没有Git也可以在仓库首页选择 **Code → Download ZIP**，解压后在终端进入其中的 `02_分析产物/图谱浏览器开发环境` 文件夹，再执行最后两条命令。已经下载项目的读者也从该文件夹开始，无需重复克隆。

确认终端显示Vite启动成功后，**保持终端运行，在同一台电脑的浏览器地址栏手动输入**：

```text
http://127.0.0.1:41839/atlas.html
```

`127.0.0.1`代表正在使用的那台电脑。没有启动服务、关闭了终端，或换到手机和另一台电脑，这个地址都不能访问刚才运行的图册。安装依赖需要联网；遇到启动报错，应先处理终端中的错误。

请使用 `/atlas.html` 入口；根路径 `/` 下的 `index.html` 是早期安装测试页。直接双击源码中的 `atlas.html` 也不能替代以上启动步骤。

### 构建可托管的静态版本

在上述开发目录中执行：

```bash
npm exec vite build -- --config src/ui/vite.config.js
```

输出位于开发目录的 `dist-ui/`，其中 `atlas.html` 是页面入口。将整个目录交给静态文件服务即可访问；构建本身不代表已部署或发布。默认的 `npm run build` 面向早期测试入口，构建知识图册请使用上面的专用命令。

### 单独的关系图文件

仓库还保留[关系图HTML源文件](03_交付物/G_v2_模型裁定版/graph.html)。该链接在GitHub中用于查看源文件，不是在线图谱入口；如需查看该关系图，先下载完整仓库，再用浏览器打开本地的 `03_交付物/G_v2_模型裁定版/graph.html`。它不等同于包含完整解释和三维探索的知识图册。

维护时先明确要修改的内容来源，再同步页面副本、核对变更并验证相关操作。不要只修改渲染副本而遗漏来源。关系方向以 `effective_source` / `effective_target` 为准。现有内容与关系可以按实际教学需要修订，历史版本保留供比较和恢复。

下一版的变更摘要命令尚未实现，具体接口与验收条件见实施规划。当前维护不需要重跑全部建图或模型评审流程，也不要求让阅读页面依赖LightRAG。
