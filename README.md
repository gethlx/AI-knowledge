## 快速开始

**查看正式图谱**（无需构建，浏览器直接打开）：

```
03_交付物/G_v2_模型裁定版/graph.html
```

**运行图谱浏览器候选**（移动优先图册，59号复验通过）：

```bash
cd 02_分析产物/图谱浏览器开发环境
npm install
npm exec vite build -- --config src/ui/vite.config.js   # 构建候选到 dist-ui/
npm run dev                                             # http://127.0.0.1:41839/atlas.html
```

依赖：Node ≥ 22.12；三维渲染依赖 `3d-force-graph` + `three-spritetext`，图标 `@phosphor-icons/web`。
